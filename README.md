# InAmigos Foundation  

Awareness Webpage | Task 1

**Live Site:** [https://inamigos7.netlify.app/]

## 📖 Project Overview
This project is an immersive, fully responsive awareness webpage developed for the **InAmigos Foundation** (a Section 8, ISO 9001:2015 certified NGO). It was built as part of the Web Development Internship Task 1 to showcase the NGO's mission, ongoing projects, and social impact.

The design focuses on a modern "Bento Box" UI, glassmorphism, and high-performance vanilla web technologies to create an engaging user experience without the bloat of heavy frameworks.

## ✨ Key Features
* **Immersive Video Wall Hero:** A dynamic, grid-based background video wall that auto-plays behind a frosted-glass Hero card.
* **Floating Glassmorphism Navigation:** A custom, scroll-aware sticky navbar that glides out of the way to maximize screen real estate.
* **Map-Colored Bento Grid:** The "Our Initiatives" section utilizes advanced CSS Grid techniques and color theory (Graph Theory Map Coloring) to ensure adjacent project cards never share the same background color.
* **Dynamic Statistics Counter:** Vanilla JavaScript intersection observers trigger a smooth 0-to-target number counting animation when the user scrolls to the impact section.
* **Custom Image Slider:** A lightweight, dependency-free JavaScript image carousel for the gallery and a cross-fade slider for the About section.
* **100% Responsive:** Flawless scaling from 4K desktop monitors down to mobile screens.

## 🛠️ Tech Stack
Built entirely with foundational web technologies to ensure maximum performance and clean architecture:
* **HTML5:** Semantic structure and accessibility.
* **CSS3:** Advanced CSS Grid, Flexbox, Custom Variables, and Backdrop Filters.
* **Vanilla JavaScript (ES6+):** For scroll animations, counting logic, and image sliders.
* **Typography:** Fontshare (Switzer Variable Font).

## 📂 Project Structure
To keep the codebase incredibly lightweight and maintainable, the core logic is isolated into strictly two files:
* `index.html` - The structural markup and inline JavaScript logic.
* `style.css` - All styling, layout grids, and animations.
* `media` - All pictures and videos used are in the same folder.
